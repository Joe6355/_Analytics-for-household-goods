# Аналитика товаров для дома

Учебный проект по фулстек-разработке. Это настольное приложение для сравнения предложений магазинов и оценки того, сколько стоит использование бытовых товаров.

## Команда и стек

- Каримов Булат Рафисович — тимлид.
- Дудин Сергей Васильевич.

Стек по требованию преподавателя — **Python, PyQt6 и Qt Designer**. Интерфейс хранится в форме Qt Designer. Python и PyQt6 понадобятся при подключении логики. Личный кабинет, история запросов и удалённая база данных — последний этап. У команды будет сервер, детали подключения появятся позже.

## Функции приложения

| Раздел | Что нужно реализовать |
| --- | --- |
| Расход | По фактическим замерам рассчитать средний расход, стоимость одного применения и число полных применений из упаковки. |
| Цены | Сравнить предложения по цене за 100 мл, 100 г или 1 штуку. Поддержать ручной ввод и загрузку по ссылке на карточку товара. Для загрузки предпочтителен разбор HTML. API тоже допустим. |
| Прогноз | По частоте использования определить, на сколько дней хватит упаковки, сколько будет применений и сколько товара и денег уйдёт за месяц и год. |
| Характеристики | Показать и проанализировать состав, объём или количество в упаковке и эффективность товара. В макете эффективность представлена долей успешных применений в серии испытаний. |
| Личный кабинет | Добавить вход и регистрацию. Хранить историю запросов в удалённой БД и показывать её в кабинете пользователя. |

## Что уже сделано

В `main` лежит [household_goods.ui](household_goods.ui) на основе доработанной формы `household_goods_v4 (2).ui`. В ней пять экранов — «Расход», «Цены», «Прогноз», «Характеристики» и «Личный кабинет». Для оформления использованы компактные формы, таблицы и тёмное боковое меню. Зона под меню пустая. Рабочая область имеет ограничение по ширине для больших окон.

В предпросмотре можно переключать страницы, вводить текст и выбирать значения. Окно открывается на экране «Расход». Числа и строки в таблицах демонстрационные. Подключение расчётов, загрузки цен, анализа, входа и сохранения истории — отдельная задача. На текущем этапе в `main` хранятся форма и описание проекта.

Раньше был рабочий прототип с калькулятором, сравнением цен, прогнозом и анализом характеристик. По просьбе автора код прототипа убрали из текущей ветки, чтобы отдельно доработать форму. Формулы и разбор HTML можно посмотреть в истории Git при возвращении к логике. [Ранний прототип](https://github.com/Joe6355/_Analytics-for-household-goods/tree/43c41db90027f01082dbd7b0ce3f2e58d4c2de20)

## Как открыть на другом компьютере

```powershell
git clone https://github.com/Joe6355/_Analytics-for-household-goods.git
cd _Analytics-for-household-goods
```

В Qt Designer нажми **Ctrl+O**, выбери `household_goods.ui` и нажми **Ctrl+R** для предпросмотра. Для просмотра достаточно Qt Designer. Пункты слева переключают страницы.

## Как продолжить с GPT

Открой папку репозитория в новом чате и попроси GPT прочитать `README.md` и `household_goods.ui`. Укажи, что именно нужно изменить в этой версии проекта.

До отдельной задачи на реализацию работаем с макетом. Переходы уже настроены в форме — сигнал `sectionList.currentRowChanged(int)` вызывает `sectionStack.setCurrentIndex(int)`. При подключении логики начни с расхода, затем перейди к ценам, прогнозу и характеристикам. Для сверки расчёта можно взять пример из формы. При 500 мл за 349 ₽ и замерах 8,5, 9 и 9,5 мл средний расход составляет 9 мл, стоимость применения — 6,28 ₽, а упаковки хватает на 55 полных применений.

Проект ведётся в [репозитории Joe6355/_Analytics-for-household-goods](https://github.com/Joe6355/_Analytics-for-household-goods). Каждый завершённый этап отправляем отдельным коммитом. На этом компьютере коммиты оформлены от `DudinSergey`. На другом ПК настрой имя и почту автора Git и доступ к репозиторию. Сообщения коммитов пишем от первого лица по этому образцу.
