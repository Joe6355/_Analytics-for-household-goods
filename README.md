# Аналитика товаров для дома

Настольное приложение для расчёта расхода и стоимости использования бытовых товаров. Стек проекта — Python, PyQt6 и Qt Designer.

## Запуск на Windows

Нужен Python 3.10 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Файлы `.ui` из папки `ui` можно открыть в Qt Designer. Приложение загружает их при запуске.

## Расход

Введите цену и количество в упаковке. Укажите фактические замеры расхода за одно применение в тех же единицах, по одному замеру на строку. Дробные значения принимаются с запятой или точкой.

Например, для упаковки 500 мл за 350 ₽ и замеров 18, 20 и 22 мл средний расход составляет 20 мл. Упаковки хватит на 25 полных применений по 14 ₽ каждое.
