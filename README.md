# Аналитика товаров для дома

Учебный проект по фулстек-разработке. Это настольное приложение для сравнения предложений магазинов и оценки того, сколько стоит использование бытовых товаров.

## Команда и стек

- Каримов Булат Рафисович — тимлид.
- Дудин Сергей Васильевич.

Стек по требованию преподавателя — **Python, PyQt6 и Qt Designer**. Форма создана в Qt Designer, приложение работает на Python и PyQt6. Сервер личного кабинета использует стандартные модули Python, включая SQLite. Сейчас клиент и сервер проверяются на одном компьютере.

## Функции приложения

| Раздел | Что нужно реализовать |
| --- | --- |
| Расход | По фактическим замерам рассчитать средний расход, стоимость одного применения и число полных применений из упаковки. |
| Цены | Сравнить предложения по цене за 100 мл, 100 г или 1 штуку. Поддержать ручной ввод и загрузку по ссылке на карточку товара. Для загрузки предпочтителен разбор HTML. API тоже допустим. |
| Прогноз | По частоте использования определить, на сколько дней хватит упаковки, сколько будет применений и сколько товара и денег уйдёт за месяц и год. |
| Характеристики | Проанализировать состав, показать объём или количество в упаковке и оценить эффективность по доле успешных применений. |
| Личный кабинет | Добавить вход и регистрацию. Хранить историю запросов в удалённой БД и показывать её в кабинете пользователя. |

## Что уже сделано

Форма [household_goods.ui](household_goods.ui) содержит пять экранов — «Цены», «Расход», «Прогноз», «Характеристики» и «Личный кабинет». При запуске открываются «Цены». В нижней части бокового меню отображается изображение `household-goods-sidebar.png`. Рабочая область имеет ограничение по ширине для больших окон.

В приложении кнопка «Рассчитать расход» проверяет поля, усредняет замеры и выводит стоимость одного применения и число полных применений. Вводи по одному замеру на строку в единицах, выбранных для упаковки. В дробных числах можно использовать запятую или точку. При изменении входных данных результат очищается до следующего расчёта.

При смене единицы на вкладке «Расход» введи фасовку и замеры заново. Для проверки возьми пример из формы. При 500 мл за 349 ₽ и замерах 8,5, 9 и 9,5 мл средний расход составляет 9 мл, стоимость применения — 6,28 ₽, а упаковки хватает на 55 полных применений.

На вкладке «Цены» нажми **«Новый список»** и укажи товар. Переключайся между списками в выпадающем поле. Меню **«Действия»** позволяет переименовать или удалить открытый список. Для удаления списка с предложениями понадобится подтверждение. В каждом списке свои предложения и единица сравнения. Для ручного ввода укажи магазин, количество в упаковке и цену. Длинные названия переносятся внутри ячейки. Таблица сортирует предложения по стоимости за 100 мл, 100 г или одну штуку. Лучшая цена считается внутри открытого списка. Чтобы сменить единицу в нём, сначала удали его предложения.

Вставь ссылку на карточку и нажми **Enter** или «Добавить по ссылке». Если в HTML есть цена в рублях и однозначная фасовка, строка с названием, магазином, упаковкой и ценой сразу появится в таблице. Объём в литрах переводится в миллилитры, масса в килограммах — в граммы. Если фасовка не определилась, заполни её в форме и нажми «Добавить».

Если в названии указано «3 × 900 мл» или «2 шт по 900 мл», приложение подставит общий объём набора. Так цена за 100 мл сопоставима с ценой одиночной упаковки. Для диапазона объёмов и наборов с разной фасовкой объём можно указать вручную.

В Windows карточки Ozon, Wildberries, Яндекс Маркета, AliExpress, Пятёрочки, Дикси и Ленты приложение читает через Chrome или Edge. Для Магнита и Fix Price сначала пробует загрузить HTML, а при сетевой ошибке или отсутствии данных открывает карточку в браузере. Выбери Chrome или Edge браузером по умолчанию и оставь вкладку с нужной карточкой активной до завершения загрузки.

Цены и наличие зависят от магазина или региона, выбранного на сайте. Для товаров с вариантами открой точную комплектацию. Если сайт просит пройти проверку или выбрать магазин, дождись появления цены в браузере и повтори добавление по ссылке. В столбце «Дата и условия» видны время загрузки и известные условия скидки. Чтобы проверить цену снова, выбери предложение со ссылкой и нажми **«Обновить цену»**. Если магазин изменил название или фасовку, для новой карточки нужно добавить отдельное предложение.

Кнопка «Сохранить CSV» в «Ценах» сохраняет предложения открытого списка вместе с составом, ссылками и условиями цены. «Загрузить CSV» заменяет предложения в открытом списке. Загруженные строки также доступны для выбора в «Расходе», «Прогнозе» и «Характеристиках».

Для проверки сравни 750 мл за 459 ₽ и 500 мл за 319 ₽. Цена за 100 мл составит 61,20 ₽ и 63,80 ₽ соответственно. Выбери упаковку 500 мл, чтобы увидеть разницу с лучшей ценой за то же количество. В этом примере 500 мл по лучшей цене стоили бы 306 ₽, разница составит 13 ₽.

В «Расходе», «Прогнозе» или «Характеристиках» выбери товар и магазин в поле **«Предложение из „Цен“»**. В списке доступны предложения из всех сравнений. Название, фасовка и цена заполняются автоматически, выбранное предложение видно на всех трёх вкладках. Кнопка **«Взять в расчёт»** в «Ценах» открывает «Расход» с выбранной строкой. Замеры и результаты испытаний сохраняются для списка товара и единицы измерения, поэтому при смене магазина для того же товара их можно использовать снова. Условие скидки отображается в сводке лучшей цены, в «Расходе» и в «Прогнозе». Ручное изменение цены убирает условие из расчёта.

Для показа всех вкладок используй [сценарий для защиты](#сценарий-для-защиты).

На вкладке «Прогноз» выбери предложение, укажи число применений в месяц или в год и нажми «Рассчитать». Если для товара ещё нет замеров, добавь их в «Расходе». Срок упаковки оценивается по полным применениям при равномерном использовании в течение года из 365 дней. При вводе частоты за год результат за месяц показывает среднее. Стоимость за период рассчитывается пропорционально использованному количеству товара.

График показывает остаток одной упаковки за первые 30 дней. Он вычитает расход за полные применения с указанной частотой и оставляет остаток, которого уже не хватит на ещё одно применение. Если изменить исходные данные, график обновится после следующего расчёта.

При 16 применениях в месяц упаковки из примера хватит примерно на 105 дней. За месяц уйдёт 144 мл на 100,51 ₽, за год — 1 728 мл на 1 206,14 ₽.

В «Характеристиках» выбор предложения подставляет состав из карточки и открывает разбор. Если магазин состав не указал, впиши компоненты с этикетки и нажми «Проанализировать состав». Таблица показывает название, долю, назначение и особенности известных групп компонентов. Десятичные запятые, текст в скобках и перечни масел в одной парфюмерной композиции сохраняются вместе. Для оценки безопасности готового средства сверяй концентрации и предупреждения на упаковке. [Группы компонентов по EPA](https://www.epa.gov/saferchoice/safer-choice-master-criteria-safer-chemical-ingredients), [Маркировка моющих средств по ECHA](https://echa.europa.eu/content-labelling-detergents)

Размер упаковки и замеры берутся из вкладки «Расход». Например, 9 мл за применение из упаковки 500 мл составляют 1,8 % её объёма. Для эффективности укажи число испытаний и успешных применений по одному критерию. При восьми успехах из десяти приложение покажет 80 %. Если одно применение стоит 2 ₽, затраты на одно успешное применение составят 2,50 ₽. Кнопка «Сохранить оценку» записывает результаты в историю аккаунта.

Списки сравнения и текущие данные расчёта автоматически сохраняются в `data/workspace.json` примерно через полсекунды после изменений. При закрытии окна приложение сразу сохраняет то, что было изменено после последнего сохранения. Следующий запуск восстановит предложения, ссылки, замеры и параметры прогноза. Если файл повреждён, приложение показывает предупреждение и сохраняет копию `data/workspace.backup-*.json` перед записью нового черновика. Вход в личный кабинет для этого не нужен.

В «Личном кабинете» можно зарегистрироваться, войти, просмотреть свою историю и выйти. Почта используется как логин, для регистрации нужен пароль длиной от 15 до 128 символов. Таблица показывает последние 100 действий аккаунта. Поиск находит текст в названии товара, действии и подробностях. Нажми строку, чтобы увидеть исходные данные и весь результат под таблицей. Кнопка «Копировать запись» копирует его вместе с датой и названием товара. «Открыть расчёт» возвращает в нужную вкладку с сохранёнными параметрами расхода, прогноза, состава или эффективности. У старых записей и записей из CSV доступны сохранённые подробности.

Кнопка «Загрузить CSV» открывает сохранённую историю в таблице. Пока открыт CSV, серверные ответы сохраняются в памяти и просмотр файла остаётся на экране. Кнопка «История аккаунта» возвращает серверную историю и обновляет её. Импорт работает локально, записи из файла на сервер не отправляются. Вход, выход или завершение сеанса сбрасывают просмотр CSV.

«Сохранить CSV» экспортирует открытый журнал вместе с подробностями действий. Файл записывается в UTF-8 с BOM и разделителем `;`. Столбцы — `Дата`, `Товар`, `Действие`, `Подробности`. Старые файлы с первыми тремя столбцами также поддерживаются. Существующий файл заменяется после успешной записи.

Раньше был рабочий прототип с калькулятором, сравнением цен, прогнозом и анализом характеристик. По просьбе автора код прототипа убрали из текущей ветки, чтобы отдельно доработать форму. Формулы и разбор HTML можно посмотреть в истории Git при возвращении к логике. ## Как открыть на другом компьютере

```powershell
git clone https://github.com/Joe6355/_Analytics-for-household-goods.git
cd _Analytics-for-household-goods
```

В Qt Designer нажми **Ctrl+O**, выбери `household_goods.ui` и нажми **Ctrl+R** для предпросмотра. Для просмотра достаточно Qt Designer. Пункты слева переключают страницы.

Для запуска приложения на Windows с Python 3.14 выполни из папки проекта:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Если `pip` сообщает об ошибке длинного пути при установке PyQt6, склонируй проект в папку с коротким путём и создай окружение там.

В PyCharm открой папку проекта, выбери `.venv\Scripts\python.exe` как интерпретатор и запусти конфигурацию с `main.py`. При запуске `main.py` сам загружает форму `household_goods.ui`.

## Как проверить личный кабинет

В отдельном терминале из папки проекта запусти сервер и оставь его открытым.

```powershell
.\.venv\Scripts\python.exe account_server.py
```

Сервер слушает `http://127.0.0.1:8765` и создаёт базу `data/accounts.sqlite3`. Во втором терминале запусти `.\.venv\Scripts\python.exe main.py`. Зарегистрируй тестовый аккаунт во вкладке «Личный кабинет», выполни расчёт расхода и открой историю. Записи сохраняются между перезапусками сервера. Пароли хранятся в виде хешей с отдельной солью для каждого аккаунта. [Хранение паролей по OWASP](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html#pbkdf2)

Когда команда разместит сервер, в клиенте можно будет указать его HTTPS-адрес через переменную `HOUSEHOLD_API_URL`. Сервер из репозитория слушает локальный интерфейс, поэтому для доступа с другого компьютера понадобится HTTPS-прокси на сервере команды. Встроенный `http.server` предназначен для учебного запуска. [Документация Python](https://docs.python.org/3/library/http.server.html)

## Сценарий для защиты

Для показа на Windows [установи зависимости](#как-открыть-на-другом-компьютере) и проверь, что браузер по умолчанию — Chrome или Edge. [Запусти сервер и приложение](#как-проверить-личный-кабинет) в отдельных терминалах.

1. В «Личном кабинете» зарегистрируй тестовый аккаунт. Для локального показа можно использовать `demo@example.test`. Укажи пароль длиной от 15 символов. Если аккаунт уже есть после репетиции, нажми «Войти».
2. В «Ценах» создай список «Fairy Зелёное яблоко 900 мл». Вставь каждую ссылку отдельно, нажми **Enter** и дождись появления строки на 900 мл. Пока приложение читает карточку, оставь её вкладку активной в браузере. Покажи цену за упаковку, цену за 100 мл и условие скидки, если оно есть. [Магнит](https://magnit.ru/product/1000112187-fairy_sr_vo_dlya_mytya_posudy_zelen_yabloko_900ml_prokter_12), [Яндекс Маркет](https://market.yandex.ru/card/sredstvo-dlya-mytya-posudy-fairy-zelenoye-yabloko-900-ml/4850591942)
3. Выбери «Магнит» и нажми «Взять в расчёт». В «Расходе» введи `8` и `10` на отдельных строках и нажми «Рассчитать расход». Средний расход будет **9 мл**, упаковки хватит на **100 полных применений**. Вернись в «Цены», перенеси предложение Маркета и повтори расчёт с уже заполненными замерами. Стоимость применения равна цене упаковки, делённой на 100.
4. В «Прогнозе» выставь **20 применений в месяц** и нажми «Рассчитать». Покажи срок упаковки около **152 дней**, расход **180 мл за месяц** и **2160 мл за год**. Суммы в рублях зависят от цены выбранного предложения.
5. Для примера укажи в «Характеристиках» 10 испытаний и 8 успешных применений. Приложение покажет эффективность **80 %**. Если в карточке доступен состав, нажми «Проанализировать состав».
6. В «Личном кабинете» покажи записи о загрузке цен, сравнении, расчётах расхода и прогнозе. Выбери строку с прогнозом, чтобы показать подробности, и нажми «Открыть расчёт». После закрытия и повторного запуска приложения замеры и предложения восстановятся. Для просмотра истории войди в тот же аккаунт.

На проверке 23 ноября 2026 года Магнит показал 239,99 ₽ за упаковку, а Маркет — 242 ₽ с Яндекс Пэй. Для предложения Маркета вышло 2,42 ₽ за применение, 48,40 ₽ в месяц и 580,80 ₽ в год. При показе пользуйся ценой, которую вернул магазин для твоего региона.

Если карточка недоступна во время показа, создай отдельный список и вручную добавь две учебные строки по 900 мл за 240 ₽ и 270 ₽. После «Взять в расчёт» впиши название товара в «Расходе». Для второй строки с теми же замерами и частотой получишь 2,70 ₽ за применение, 54 ₽ в месяц и 648 ₽ в год.

## Автоматические проверки

При отправке коммитов и обновлении запросов на слияние в `main` GitHub запускает тесты на Windows с Python 3.14. Тесты проверяют расчёты, импорт карточек на сохранённых примерах и работу с локальными данными. Результаты доступны в [GitHub Actions](https://github.com/Joe6355/_Analytics-for-household-goods/actions).

Локальный запуск тестов из папки проекта:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Как продолжить с GPT

Открой папку репозитория в новом чате и попроси GPT прочитать `README.md` и `household_goods.ui`. Укажи, что именно нужно изменить в этой версии проекта.

Для перехода к удалённой БД нужен адрес сервера команды. На текущем этапе сценарий демонстрируется с отдельным локальным сервером. Переходы настроены в форме — сигнал `sectionList.currentRowChanged(int)` вызывает `sectionStack.setCurrentIndex(int)`.

Проект ведётся в [репозитории Joe6355/_Analytics-for-household-goods](https://github.com/Joe6355/_Analytics-for-household-goods). Каждый завершённый этап отправляем отдельным коммитом. На этом компьютере коммиты оформлены от `DudinSergey`. На другом ПК настрой имя и почту автора Git и доступ к репозиторию. Сообщения коммитов пишем от первого лица по этому образцу.

```text
сделал:
- обновил форму в qt дизайнере
- описал проект и следующие шаги в readme
```
