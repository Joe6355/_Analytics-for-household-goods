# Аналитика товаров для дома

Настольное приложение для расчёта расхода и стоимости использования бытовых товаров. Стек проекта — Python, PyQt6 и Qt Designer.

## Запуск на Windows

Нужен Python 3.10 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Файлы `.ui` из папки `ui` можно открыть в Qt Designer. Приложение загружает их при запуске.

## Расход

Введите цену и количество в упаковке. Укажите фактические замеры расхода за одно применение в тех же единицах, по одному замеру на строку. Дробные значения принимаются с запятой или точкой.

Например, для упаковки 500 мл за 350 ₽ и замеров 18, 20 и 22 мл средний расход составляет 20 мл. Упаковки хватит на 25 полных применений по 14 ₽ каждое.

## Сравнение цен

Добавьте предложения для одного товара с указанием магазина, цены и количества в каждой упаковке. Сравнение идёт по цене за 100 мл, 100 г или 1 шт. в зависимости от выбранной единицы.

Вставьте ссылку на карточку и нажмите «Загрузить цену», чтобы заполнить магазин и цену. Приложение читает разметку товара с ценой в рублях из HTML. Если цена появляется только после загрузки JavaScript или магазин закрывает доступ к странице, введите цену вручную. Количество в упаковке вводится вручную в обоих случаях.

Чтобы проверить сравнение на одном товаре, загрузите две карточки геля Velly и укажите 500 мл для каждой упаковки. [Grass MO](https://grass-mo.ru/catalog/klining/sredstva_dlya_posudomoechnykh_mashin/4318/), [ТутХимия](https://tuthimiya.ru/cat/gel-dlya-mytya-posudy-v-posudomoechnyh-mashinah-velly-flakon-500-ml/).

## Прогноз

Заполните вкладку «Расход», затем укажите число применений в месяц или в год. Приложение покажет, на сколько дней хватит упаковки, а также среднее число применений, расход товара и его стоимость в месяц и в год.

Срок рассчитывается по числу полных применений и году из 365 дней. Стоимость пропорциональна количеству использованного товара. При 8 применениях в месяц упаковки из примера хватит примерно на 95 дней, а стоимость расхода составит 112 ₽ в месяц и 1 344 ₽ в год.

## Характеристики

Введите компоненты с этикетки по одному на строку. Приложение покажет число уникальных компонентов. Если добавить второй состав, оно выделит общие компоненты и различия. Строки сравниваются без учёта регистра и лишних пробелов.

Размер упаковки и доля, которая уходит за одно применение, берутся из замеров на вкладке «Расход». Для оценки эффективности укажите число испытаний и число успешных применений по одному критерию.
